1. Бидний цуглуулдаг мэдээлэл

Бид Аппыг ажиллуулах, захиалга боловсруулах, үйлчлүүлэгчдэд туслах, таны туршлагыг сайжруулахад шаардлагатай мэдээллийг л цуглуулдаг.

1.1 Таны өгсөн хувийн мэдээлэл

Та бүртгэл үүсгэх, захиалга өгөх, профайлаа шинэчлэх эсвэл бидэнтэй холбогдох үед дараах мэдээллийг цуглуулж болно:

  • Бүртгэлийн мэдээлэл — Имэйл хаяг, нууц үг (баталгаажуулалтын үйлчилгээ үзүүлэгчийн хэш хэлбэрээр хадгалагдана), харуулах нэр
  • Профайлын мэдээлэл — Бүтэн нэр, утасны дугаар, хүргэлтийн хаяг, профайлын зураг
  • Захиалгын мэдээлэл — Захиалсан бүтээгдэхүүн, тоо хэмжээ, бэлэг орох сонголт, төлбөрийн арга, нийт дүн, хүргэлтийн дэлгэрэнгүй
  • Харилцаа — Апп доторх чатаар илгээсэн мессеж (текст, зураг), тусламжийн хүсэлт
  • Хэрэглэгчийн үүсгэсэн агуулга — Бүтээгдэхүүний сэтгэгдэл, үнэлгээ, зураг болон бусад сайн дураар илгээсэн агуулга

Хэрэв та Apple Sign-In-ээр нэвтэрвэл Apple бидэнд хуваалцдаг мэдээлэл — таны нэр, имэйл (эсвэл имэйлээ нуухыг сонгосон тохиолдолд Apple-ийн private relay имэйл), мөн Apple бүртгэлтэй холбоотой давтагдашгүй таних тэмдэг — ирж болно. Бид таны Apple ID нууц үгийг хүлээн авдаггүй.

Имэйл, нууц үгээр бүртгэл үүсгэвэл та өгсөн нэвтрэх мэдээллийг цуглуулна. Нууц үгийг сервер дээр энгийн текст хэлбэрээр хадгалдаггүй.

Аппыг ашиглах үед дараах мэдээллийг автоматаар цуглуулах эсвэл хүлээн авах боломжтой:

  • Төхөөрөмжийн таних тэмдэг, push token — Таны бүртгэл, төхөөрөмжтэй холбоотой Expo push мэдэгдлийн token
  • Платформын мэдээлэл — Үйлдлийн систем (iOS эсвэл Android), аппын хувилбар, төхөөрөмжийн төрөл
  • Ашиглалт, сессийн мэдээлэл — Нэвтрэлтийн сессийн token, нэвтэрсэн цаг, Аппыг аюулгүй, тогтвортой ажиллуулахад шаардлагатай суурь оношилгооны мэдээлэл
  • Сүлжээний мэдээлэл — IP хаяг, ерөнхий холболтын мэдээлэл (зочидлох, баталгаажуулалтын үйлчилгээ үзүүлэгч боловсруулж болно)

Бид энэ мэдээллийг сурталчилгааны профайл үүсгэх, гуравдагч этгээд сурталчлагчид өгөх зорилгоор ашигладаггүй.

1.3 Медиа файл, зургийн сан

Апп таны төхөөрөмжийн зургийн санд зөвхөн та сонгосон зургийг байршуулах зорилгоор хандахыг хүсч болно — жишээ нь профайлын зураг, бүтээгдэхүүнтэй холбоотой зураг (захиалгын онцгой зураг гэх мэт).

Бид зөвхөн таны тодорхой сонгосон зургуудад хандана. Бүх зургийн сангаа уншиж, индекслэж, цуглуулдаггүй. Сонгосон зургуудыг Апп дотор харуулахын тулд аюулгүй үүлэн хадгалалтад байршуулж болно (профайл, чат, сэтгэгдэл гэх мэт).

Одоогийн хувилбарт камер, микрофоны эрхийг хүсдэггүй; зөвхөн зургийн сангаас сонгох тохиргоотой.

Зөвшөөрөл өгсөн тохиолдолд бид таны бүртгэлтэй холбоотой Expo push token-ийг хадгалж, захиалгын төлөв, чатын мессеж, тусламжийн хариу болон бусад үйлчилгээний мэдэгдлийг илгээнэ.

  • Захиалга боловсруулах — Худалдан авалт биелүүлэх, дүн тооцох, хүргэлтийн мэдээлэл бүртгэх, төлөв мэдэгдэх
